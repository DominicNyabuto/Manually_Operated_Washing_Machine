# Design of a Manually Operated Washing Machine

This repository contains the design, fabrication details, and documentation for a Pedal Powered Washing Machine (PPWM) developed at the Department of Mechanical Engineering, Kenyatta University.

## Project Overview
The PPWM is a low-cost, environmentally friendly washing machine constructed from readily available scrap materials. It utilizes human pedaling power to generate rotary motion, completely eliminating the need for electricity.
This project addresses the practical challenges of laundry in rural areas with limited electrification, which currently ranges between 40-45% in Kenya. It provides a durable, affordable alternative to expensive electric washing machines while significantly reducing the physical strain associated with traditional hand-washing.  

## Key Features and Objectives
- Electricity-Free Operation: Powered entirely by human pedaling, making it ideal for off-grid rural areas.
- High Efficiency: The power transmission system achieves a mechanical efficiency of 75%.
- Automated-Style Cycles: Capable of performing comprehensive washing and rinsing cycles similar to automatic machines currently on the market.
- Cost-Effective Production: The estimated production budget for the prototype is approximately Ksh. 5250, ensuring it remains accessible for low-income households.
- Ergonomic Design: Features a seated metallic frame that allows the user to pedal comfortably, enabling even physically handicapped individuals or children to do laundry without excessive back strain.

To operate the machine, the outer drum is filled halfway with water and detergent, and the inner drum is loaded with clothing.   The user sits on the frame and presses the bicycle-style pedals. This pedaling motion drives a standard 3/32" multi-speed bicycle chain connected between a large driver sprocket and a smaller driven sprocket mounted on a catcher. The smaller sprocket turns a 78cm long, 20mm-diameter solid shaft that is fixed to the inner drum, causing it to rotate. As the inner drum spins, the water agitates and rubs against the clothing, thoroughly cleaning the load.
